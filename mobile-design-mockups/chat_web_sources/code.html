Chat — distinguer les pages web des médias (DRAFT-1)

Le chat peut désormais chercher sur le web. Une réponse cite alors deux familles de sources : les médias du dossier, comme aujourd'hui (surligné ambre, titre du média), et les pages web, dans une nouvelle couleur bleu encre, avec un globe et le nom du site. Un appui sur une source média ouvre le média dans l'app ; un appui sur une source web ouvre la page dans le navigateur.

Retenu par l'owner (2026-11-06) : B. L'ambre reste la couleur de tes médias. Les pages web prennent un bleu encre, de la même famille de teintes que les gris-bleus du système. Le globe sert de deuxième indice, pour qui distingue mal les couleurs, et le nom du site dit d'où vient l'information. La liste sous la réponse montre le titre complet de chaque page et rend visible le fait que le chat est allé sur le web. Le web reprend le même rendu dans le panneau de chat.
