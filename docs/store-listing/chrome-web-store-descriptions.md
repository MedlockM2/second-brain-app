# Chrome Web Store — descriptions traduites (copier-coller)

Où les coller : tableau de bord → Deepn → **Fiche Store** → menu de langue en haut
(« anglais – en (par défaut) ») → choisir la langue → champ **Description** →
« Enregistrer le brouillon ». Une fois toutes les langues faites : « Envoyer pour examen ».

Le résumé (première ligne de la fiche) vient du package (`extension/public/_locales/*/messages.json`,
clé `extDescription`) : il est déjà traduit, rien à faire.

Les noms d'onglets (Cahier, Notizbuch, Cuaderno…) et le registre (vous / du / tú…) reprennent
ceux de l'interface de l'extension dans chaque langue.

## en (par défaut) — version corrigée

Corrections par rapport au texte en ligne : « LinkedIn » (et non « Linkedin »), « any website »,
point final manquant.

```
Understand more of what you read, watch, and listen to. Deepn pulls out the key ideas, lets you ask follow-up questions, and turns what you find into notes, flashcards, and quizzes you can come back to.

Use it with articles from any website, LinkedIn, YouTube videos, and podcast episodes from Spotify, Apple Podcasts, Deezer…

Click the Deepn icon or press Alt+S to save the current page and open the side panel. Right-click to save a link without opening it or turn selected text into a note. Explore what you saved in the side panel or open Notebook to create study materials.

```
